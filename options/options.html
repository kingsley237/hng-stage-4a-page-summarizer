Gemini API Key

Your API key is stored locally on your device and never sent anywhere except Google's Gemini API.

Get a free key at Google AI Studio — no credit card required.

How to get your API key

  1. Go to Google AI Studio
  2. Sign in with your Google account
  3. Click Create API Key
  4. Copy the key and paste it above
  5. Click Save Key

The free tier includes generous daily limits — more than enough for regular use.
